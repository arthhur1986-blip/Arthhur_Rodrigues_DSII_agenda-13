# Hotel Horizonte

Projeto de Arthhur Rodrigues para Desenvolvimento de Sistemas II, Agenda 13 (2026).

O aplicativo .NET MAUI permite definir o número de hóspedes, escolher uma suíte e informar as datas de entrada e saída. A tela de resumo mostra o número de diárias e o total estimado em reais. O botão **Sobre** na tela inicial abre os créditos do projeto.

As tarifas são fictícias e cobradas por suíte por noite. O aplicativo simula valores de hospedagem.

## Executar

1. Instale o SDK do .NET 8 e a carga de trabalho **Desenvolvimento de interface do usuário de aplicativo multiplataforma .NET** no Visual Studio 2022.
2. Abra `MauiAppHotel.sln`.
3. Selecione **Windows Machine** ou um emulador Android e pressione **F5**.
